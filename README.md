# Heksa the Rasberry Pi powered Hexapot robot
Heksa is a Hexabot robot project based on [Make your own pet](https://github.com/makeyourpet/hexapod) and [Robert Meisner's tech Workbench for Rasberry Pi build instructions](https://github.com/robs-tech-workbench/hexapod_spiderbot_tutorials) with Rasberry Pi 4
