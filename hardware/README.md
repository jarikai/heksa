# This folder includes information about hardware used to build Rasberry Pi powered Heksa robot.

Heksa is using these repositories and websites for instructions:
1. [Make your pet repository](https://github.com/makeyourpet/hexapod)
2. [Robert Meisner's tech Workbench for Rasberry Pi build instructions](https://github.com/robs-tech-workbench/hexapod_spiderbot_tutorials)
3. [Robert Meisner's 3D files guide](https://github.com/robs-tech-workbench/hexapod_spiderbot_model)

![Heksa with current state](/images/20251120_110612.jpg "Heksa with current state")
At this state we have been testing it with the Android Chica client to get basic movments working. After some testing one leg was broken, because we had to use plastic servo mounting parts from servo backage. I just ordered 15 servo mount.
